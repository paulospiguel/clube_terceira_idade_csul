# 0007 — Prestação de contas pública

**Estado:** aceite (2026-11-22)

## Decisão
A página de Prestação de contas é pública: qualquer Visitante vê os registos e documentos, sem login.

## Consequências
- Não é preciso login de Sócio (reforça ADR 0002).
- O painel deve avisar o Gestor, antes de publicar um documento, para ocultar CPF, dados bancários e outros dados pessoais.
- Documentos ficam acessíveis por URL pública no R2 e podem ser indexados por motores de busca.
