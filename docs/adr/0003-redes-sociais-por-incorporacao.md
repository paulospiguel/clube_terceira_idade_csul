# 0003 — Instagram e Facebook por incorporação, sem importação

**Estado:** aceite (2026-11-22)

## Decisão
O Feed social é incorporado (embed) a partir do Instagram e do Facebook. O conteúdo não é copiado para a base de dados do site.

## Consequências
- Menos manutenção: sem tokens da API Meta a renovar para importar.
- Aparência do feed fica limitada ao que o embed permite.
- Posts do Instagram não aparecem na pesquisa interna do site.
